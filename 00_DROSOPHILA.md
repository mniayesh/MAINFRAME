## SECTION 1.1: Cable Theory & Passive Properties

### Formula 1.1: Cable Equation (Continuous Form)

**Name & Purpose:**
Classical cable equation governing voltage propagation along axons/dendrites with passive membrane properties. Foundation for all compartmental neuron models.

**Formula/Equation:**
```
Cm × ∂V/∂t = (1/Ra) × ∂²V/∂x² - V/Rm + I_syn

Variables:
  Cm = specific membrane capacitance = 0.8-2.57 µF/cm² (Drosophila)
  Ra = intracellular resistivity = 163.9-224 Ω·cm
  Rm = specific membrane resistance = 8,300-19,200 Ω·cm²
  V = membrane potential (mV)
  x = distance along neurite (µm)
  t = time (ms)
  I_syn = synaptic input current (mA/cm²)
```

**Natural Description:**
The cable equation describes voltage propagation along cylindrical neuronal processes. For Drosophila projection neurons (antennal lobe), dendritic trees extend 46+ micrometers. Voltage significantly attenuates with distance due to passive membrane leak and axial resistance. The equation balances three currents: capacitive charging (first term), longitudinal current flow (second term), and resistive membrane leak (third term).

**Drosophila Circuit Application:**
- Antennal lobe projection neurons: 46 µm dendritic extent
- Mushroom body Kenyon cells: 150-300 µm cable length
- Motor neurons: 300-800 µm cable length
- Determines dendritic integration window and synaptic weight attenuation

**AI Architecture Impact:**
Foundation for **ARCH-9 (Dual-Channel Neurons)** and **ARCH-10 (Multi-Timescale RNN)**. The cable equation naturally separates into fast (capacitive) and slow (resistive) components. Different dendritic compartments have different time constants (τ = Rm×Cm = 6.6-49.4 ms), enabling multi-timescale processing without explicit design.

**PyTorch Code Example:**
```python
class CableEquation(nn.Module):
    def __init__(self, Rm=13000, Ra=190, Cm=1.5):
        super().__init__()
        self.Rm = nn.Parameter(torch.tensor(float(Rm)))
        self.Ra = nn.Parameter(torch.tensor(float(Ra)))
        self.Cm = nn.Parameter(torch.tensor(float(Cm)))

    def forward(self, V, d2V_dx2, I_syn):
        # Cm dV/dt = (1/Ra) d²V/dx² - V/Rm + I_syn
        dV_dt = (1/self.Cm) * ((1/self.Ra) * d2V_dx2 - V/self.Rm + I_syn)
        return dV_dt
```

**Key Parameters (Drosophila-specific):**
- Cm = 1.5 µF/cm² (typical)
- Rm = 13,000 Ω·cm² (antennal lobe PN)
- Ra = 190 Ω·cm (axoplasm conductivity)
- τ_m = Rm × Cm = 19.5 ms (membrane time constant)
- λ = √(Rm×d/4Ra) ≈ 150 µm (space constant for d=1 µm)

**Original Source:**
ModelDB 118662 (Gouwens & Wilson, 2009): "Signal Propagation in Drosophila Central Neurons"
Fitted from whole-cell patch-clamp recordings of antennal lobe projection neurons

### Formula 1.2: Cable Equation (Discretized - Compartmental Form)

**Name & Purpose:**
Discretized cable equation for numerical simulation of multi-compartment neurons (640-1,152 compartments per Drosophila PN).

**Formula/Equation:**
```
Cm × dV_i/dt = G_i(V_parent - V_i) + G_i(V_child - V_i) - V_i/Rm + I_syn[i]

Where:
  V_i = membrane potential in compartment i (mV)
  G_i = axial conductance = π·d·a/(Ra·dx)
  d = segment diameter (µm)
  a = segment length (µm)
  V_parent, V_child = adjacent compartment voltages (mV)
  dx = compartment spacing (µm)
```

**Natural Description:**
The cable equation is discretized into a system of ordinary differential equations for each compartment. Drosophila projection neurons reconstructed from electron microscopy contain 640-1,152 compartments with diameters ranging from 0.22 µm (terminal dendrites) to 10.2 µm (soma). Each compartment couples to neighbors through axial conductance.

**Drosophila Circuit Application:**
- Kenyon cell dendrites: 100-200 compartments
- Projection neuron dendritic tree: 640-1,152 compartments
- Motor neuron axon: 300-500 compartments
- Enables location-dependent learning and plasticity

**AI Architecture Impact:**
Enables **ARCH-14 (Homeostatic Plasticity)** at compartmental level. Distal compartments (high resistance, electrically isolated) learn faster with location-specific plasticity. Proximal/soma compartments (low resistance, tightly coupled) are more stable. Matches observed Kenyon cell learning in mushroom body.

**PyTorch Code Example:**
```python
class CompartmentalNeuron(nn.Module):
    def __init__(self, n_segments=640, Rm=13000, Ra=190, Cm=1.5):
        super().__init__()
        self.n_seg = n_segments
        self.Rm, self.Ra, self.Cm = Rm, Ra, Cm
        self.V = nn.Parameter(torch.ones(n_segments) * -60.0)  # mV
        self.G_axial = self._compute_axial_conductances()

    def forward(self, I_syn, dt=0.01):
        dV_dt = torch.zeros(self.n_seg)
        for i in range(self.n_seg):
            axial_in = self.G_axial[i-1] * (self.V[i-1] - self.V[i]) if i > 0 else 0
            axial_out = self.G_axial[i] * (self.V[i] - self.V[i+1]) if i < self.n_seg-1 else 0
            leak = self.V[i] / self.Rm
            dV_dt[i] = (axial_in - axial_out - leak + I_syn[i]) / self.Cm
        self.V.data += dV_dt * dt
        return self.V
```

**Key Parameters:**
- n_segments = 640-1,152 (Drosophila PN from Hemibrain)
- Diameter range: 0.22-10.2 µm
- Total cable length: 46+ µm (dendritic extent)
- Coupling strength varies 100× between thin/thick segments

**Original Source:**
ModelDB 118662; Hemibrain v1.2 connectome morphology

### Formula 1.3: Leak Conductance

**Name & Purpose:**
Passive ion leak current across neuronal membrane; determines resting potential and baseline ATP consumption (~40% of neuron's energy budget).

**Formula/Equation:**
```
i_leak = g_leak × (V - E_leak)

Variables:
  i_leak = leak current density (mA/cm²)
  g_leak = leak conductance density = 0.0003 S/cm²
  V = membrane voltage (mV)
  E_leak = leak reversal potential = -60 mV
```

**Natural Description:**
Drosophila antennal lobe projection neurons maintain resting potential through passive ion leak via non-selective cation channels (primarily Na+). This conductance represents a major source of ATP consumption in real neurons, consuming ~40% of baseline metabolic energy to maintain ionic gradients against leak.

**Drosophila Circuit Application:**
- All Drosophila neurons: resting potential maintenance
- Energy cost scales with surface area
- Larger neurons (motor neurons) have higher total leak current
- Starvation reduces excitability by decreasing ATP available for Na/K pump

**AI Architecture Impact:**
Biophysical basis for **ARCH-7 (Energy-Aware Neurons)**. By linking passive conductance to ATP consumption, networks automatically become energy-constrained without explicit L1 regularization, achieving 60-80% sparsity naturally. Starvation (low ATP) increases firing threshold.

**PyTorch Code Example:**
```python
class LeakConductance(nn.Module):
    def __init__(self, gmax=0.0003, e_rev=-60.0):
        super().__init__()
        self.gmax = nn.Parameter(torch.tensor(gmax))
        self.e_rev = torch.tensor(e_rev)

    def forward(self, v):
        return self.gmax * (v - self.e_rev)
```

**Key Parameters:**
- g_leak = 0.0003 S/cm² (Drosophila PN)
- E_leak = -60 mV
- ATP consumption ≈ 40% of basal metabolism
- Temperature sensitive: increases ~3× per 10°C

**Original Source:**
ModelDB 118662; FlyBase gene expression data

### Formula 1.4: Voltage Attenuation (Electrotonic Decay)

**Name & Purpose:**
Exponential voltage decay with distance along dendrite due to passive membrane properties and axial resistance.

**Formula/Equation:**
```
V(x) = V₀ × exp(-x/λ)

Variables:
  V(x) = voltage at distance x from origin (mV)
  V₀ = voltage at origin (x=0) (mV)
  x = distance along dendrite (µm)
  λ = electrotonic length constant ≈ 150 µm (Drosophila PN)
```

**Natural Description:**
Signals propagating along Drosophila dendrites decay exponentially due to combination of axial resistance and membrane conductance. For projection neurons with 46+ µm dendritic extent, an input at dendrite tip experiences ~50% attenuation (exp(-46/150) ≈ 0.73) by the time it reaches soma. Somatic recordings don't accurately capture dendritic dynamics.

**Drosophila Circuit Application:**
- Projection neurons: 46 µm dendrites → 73% transmission to soma
- Kenyon cells: compact morphology → minimal attenuation
- Motor neurons: extensive dendrites → significant attenuation
- Determines effective synaptic weight as function of location

**AI Architecture Impact:**
Explains spatial attention in **ARCH-2 (Metabolic Attention)** and **ARCH-30 (Chain-Length Attention)**. Distant synaptic inputs have lower effective weight due to electrotonic attenuation. Attention weights naturally decay with sequence distance, similar to voltage decay with spatial distance.

**PyTorch Code Example:**
```python
class VoltageAttenuation(nn.Module):
    def __init__(self, lambda_electrotonic=150.0):
        super().__init__()
        self.lambda_const = nn.Parameter(torch.tensor(lambda_electrotonic))

    def forward(self, V0, distance):
        # V(x) = V0 * exp(-distance / lambda)
        V_atten = V0 * torch.exp(-distance / self.lambda_const)
        return V_atten
```

**Key Parameters:**
- λ = 150 µm (Drosophila PN, d=1 µm)
- Dendritic extent = 46 µm → 73% voltage transmission
- For Kenyon cells: λ ≈ 100 µm (thinner dendrites)
- For motor neurons: λ ≈ 200 µm (thicker processes)

**Original Source:**
ModelDB 118662 cable theory characterization

### Formula 1.5: Electrotonic Length Constant

**Name & Purpose:**
Characterizes signal propagation distance; determines how far synaptic inputs influence spike output and defines neuron compactness.

**Formula/Equation:**
```
λ = √(Rm × d / (4 × Ra))

Electrotonic distance:
L_electrotonic = L_anatomical / λ

Variables:
  λ = electrotonic length constant (µm)
  Rm = specific membrane resistance = 8,300-19,200 Ω·cm²
  d = compartment diameter (µm)
  Ra = intracellular resistivity = 163.9-224 Ω·cm
  L_anatomical = physical cable length (µm)
  L_electrotonic = dimensionless electrotonic distance
```

**Natural Description:**
The electrotonic length constant determines the "reach" of electrical signals. Drosophila projection neurons with 46 µm dendrites have L_electrotonic ≈ 0.3 (λ ≈ 150 µm), meaning the entire dendritic tree is electrotonically compact. This differs from mammalian pyramidal neurons where L_electrotonic > 1 (electrotonically extensive, significant compartmentalization).

**Drosophila Circuit Application:**
- Projection neurons: L_elec ≈ 0.3 (compact)
- Kenyon cells: L_elec ≈ 1.0-2.0 (moderately compact)
- Motor neurons: L_elec ≈ 1.5-3.0 (extensive)
- Central complex ring neurons: coupled within λ ≈ 150 µm

**AI Architecture Impact:**
Core parameter for **ARCH-16 (Kuramoto Synchronization)** with spatial decay. Central complex ring neurons (50 µm separation) synchronize locally because λ ≈ 150 µm allows moderate coupling (exp(-50/150) ≈ 0.7). Distant neurons decouple, explaining multiple parallel ring neuron copies.

**PyTorch Code Example:**
```python
class ElectronicLengthConstant(nn.Module):
    def __init__(self, Rm=13000, Ra=190, diameter=1.0):
        super().__init__()
        self.Rm = nn.Parameter(torch.tensor(float(Rm)))
        self.Ra = nn.Parameter(torch.tensor(float(Ra)))
        self.d = nn.Parameter(torch.tensor(float(diameter)))

    def forward(self):
        # λ = √(Rm × d / (4 × Ra))
        lambda_const = torch.sqrt((self.Rm * self.d) / (4.0 * self.Ra))
        return lambda_const
```

**Key Parameters:**
- λ = 150 µm (Drosophila PN, d=1 µm, Rm=13000 Ω·cm²)
- Kenyon cell: λ ≈ 100 µm (d=0.5 µm)
- Motor neuron: λ ≈ 200 µm (d=2 µm)
- Determines spatial extent of synchrony and coupling

**Original Source:**
Cable theory; ModelDB 118662

### Formula 1.6: Membrane Time Constant

**Name & Purpose:**
Integration time window for synaptic inputs; determines STDP plasticity window, learning speed, and response kinetics.

**Formula/Equation:**
```
τ_m = Rm × Cm

Variables:
  τ_m = membrane time constant (ms)
  Rm = specific membrane resistance = 8,300-19,200 Ω·cm²
  Cm = specific membrane capacitance = 0.8-2.57 µF/cm²

Drosophila range: τ_m = 6.6-49.4 ms
  - Distal dendrites (small surface area): τ_m ≈ 6.6 ms (fast)
  - Soma (large surface area): τ_m ≈ 49.4 ms (slow)
```

**Natural Description:**
The membrane time constant determines how long voltage changes persist. For Drosophila projection neurons, fast compartments (small diameter terminal dendrites, low capacitance) have τ_m ≈ 6.6 ms, while slow compartments (large soma, high capacitance) have τ_m ≈ 49.4 ms. This 7-fold variation means synaptic inputs at different locations integrate on different timescales.

**Drosophila Circuit Application:**
- STDP time window: ±τ_m ≈ ±20 ms
- Kenyon cells: fast τ_m ≈ 10 ms (rapid odor sampling)
- Projection neurons: medium τ_m ≈ 20 ms (temporal integration)
- Motor neurons: variable τ_m (different compartment roles)

**AI Architecture Impact:**
Directly parameterizes **ARCH-19 (STDP)** and **ARCH-20 (BCM)** learning windows. STDP operates on millisecond timescale of τ_m; pre-post spike intervals within τ_m cause LTP, outside cause LTD. No arbitrary hyperparameters needed—all from biology.

**PyTorch Code Example:**
```python
class MembraneTimeConstant(nn.Module):
    def __init__(self, Rm=13000, Cm=1.5):
        super().__init__()
        self.Rm = nn.Parameter(torch.tensor(float(Rm)))
        self.Cm = nn.Parameter(torch.tensor(float(Cm)))

    def compute_tau_m(self):
        # τ_m = Rm × Cm (ms)
        tau_m = self.Rm * self.Cm
        return tau_m

    def forward(self, V, I_input, dt):
        # First-order exponential filter
        tau_m = self.compute_tau_m()
        dV = (I_input - V) / tau_m
        V_new = V + dV * dt
        return V_new
```

**Key Parameters:**
- τ_m range: 6.6-49.4 ms (compartment-dependent)
- Typical PN soma: τ_m ≈ 20 ms
- Kenyon cell: τ_m ≈ 10 ms
- STDP window: ±τ_m ≈ ±20 ms

**Original Source:**
ModelDB 118662; measured from whole-cell recordings
