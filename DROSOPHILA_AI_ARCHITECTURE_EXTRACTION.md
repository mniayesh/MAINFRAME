#### [ARCH-5] Michaelis-Menten Activation
**Description:** Saturation-based activation preventing explosive responses
**Biological Source:** Universal enzyme kinetics

**Drosophila Application:**
- Synaptic transmission saturation (neurotransmitter depletion)

**Formula:**
```

```

**Where:**
- V_max = maximum firing rate
- K_m = input level for 50% response (selectivity)
- Naturally prevents unstable oscillations

#### [ARCH-19] STDP Learning (Spike-Timing Dependent Plasticity)
**Description:** Weight updates based on temporal causality
**Biological Source:** Universal synaptic plasticity
**AI Innovation:** Local learning (no backprop needed)

**Drosophila Application:**
- **Mushroom body**: STDP between antennal lobe and Kenyon cells during olfactory learning
- **Central complex**: STDP for directional learning
- **Motor circuits**: STDP for motor pattern refinement
- **Timing-based learning**: Pre-before-post strengthens causality

**Formula:**
```
if dt > 0:  # Pre before post (causal)
    dw = A_+ * exp(-dt / tau_+)  # LTP
else:  # Post before pre (anti-causal)
    dw = -A_- * exp(|dt| / tau_-)  # LTD
```

**Drosophila Timescales:**
- τ_+ ≈ 10-30 ms (fast facilitation)
- τ_- ≈ 30-60 ms (slower depression)
- Single spikes sufficient for plasticity (low threshold)
