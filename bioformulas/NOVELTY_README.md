# NOVELTY - Novel AI Architectures Derived from Biology

**Database of 42 novel neural network architectures extracted from 86,418 biological formulas**

## Quick Start

```bash
# List all architectures
python3 query_novelty.py list

# Search by keyword
python3 query_novelty.py search "metabolic"
python3 query_novelty.py search "STDP"
python3 query_novelty.py search "oscillat"

# Show full details (with code)

python3 query_novelty.py show 11  # MAPK Amplifying Cascade
python3 query_novelty.py show 16  # Kuramoto Synchronization

# Statistics
python3 query_novelty.py stats
```

### 🧬 **Metabolic Optimization (5 architectures)**

**#1: Metabolic Loss Function**
- **In Nature:** E.coli growth rate (3,894-char formula, 65 metabolites)
- **Innovation:** Multi-objective loss balancing accuracy, energy, sparsity, robustness, and 61+ other objectives
- **Key Feature:** Thermodynamically grounded (log ratios = free energy), evolution-tested 3.5B years

**#2: Metabolic Attention Mechanism**
- **In Nature:** E.coli resource allocation to maximize growth
- **Innovation:** Attention modulated by 65-objective fitness, not just accuracy
- **Key Feature:** Automatic Pareto optimization

**#3: Metabolic Neural Architecture Search**
- **In Nature:** Evolutionary metabolic network optimization
- **Innovation:** NAS using E.coli growth as fitness function
- **Key Feature:** Finds Pareto-optimal architectures without manual tuning

**#8: Metabolic Compute Budget**
- **In Nature:** Cellular ATP pool management
- **Innovation:** Global compute budget consumed by layers, regenerated by confidence
- **Key Feature:** Automatic efficiency vs accuracy trade-offs

**#24: Metabolic Cascade Network**
- **In Nature:** Cellular respiration (Glycolysis → TCA → OXPHOS)
- **Innovation:** 3-stage network: fast (6% efficient) → medium → slow (38% efficient)
- **Key Feature:** Adaptive pathway selection based on energy demand

### ⚡ **Activation Functions (3 architectures)**

**#4: Hill Activation (Adaptive Cooperativity)**
- **In Nature:** Hemoglobin oxygen binding (Hill coefficient n=2.8)
- **Innovation:** Learnable steepness parameter for sharp or smooth switching
- **Formula:** `v = x^n / (K^n + x^n)` where n is learned

**#5: Michaelis-Menten Activation**
- **In Nature:** Universal enzyme saturation kinetics
- **Innovation:** Prevents explosive activations via saturation
- **Formula:** `v = Vmax*x / (Km + x)`

**#6: Substrate Inhibition Activation**
- **In Nature:** Enzyme inhibition by excess substrate
- **Innovation:** Too much input reduces output (overconfidence prevention)
- **Formula:** `v = Vmax*x / (Km + x + x²/Ksi)`

---

### 🧠 **Learning Rules (3 architectures)**

**#19: STDP Learning (Spike-Timing Dependent Plasticity)**
- **In Nature:** Synaptic plasticity in all neurons
- **Innovation:** Temporal causality learning: pre-before-post → strengthen
- **Key Feature:** Local learning (no global backprop needed)
- **Formula:** `Δw = A₊ exp(-Δt/τ₊)` for causal, `-A₋ exp(Δt/τ₋)` for anti-causal

**#20: BCM Learning Rule (Homeostatic)**
- **In Nature:** Visual cortex development, self-organization
- **Innovation:** Sliding threshold maintains stable activity (no BatchNorm needed)
- **Formula:** `dw/dt = η φ(post - θ) pre` where θ slides

**#21: Oja's Rule (Automatic PCA)**
- **In Nature:** Hebbian learning with weight normalization
- **Innovation:** Unsupervised PCA extraction
- **Formula:** `Δw = η y (x - y w)`

### 🌊 **Oscillatory Dynamics (3 architectures)**

**#16: Kuramoto Synchronization Layer**
- **In Nature:** Brain gamma synchronization for feature binding
- **Innovation:** Features represented as phase oscillators that synchronize if related
- **Key Feature:** Binding by synchrony (solves binding problem)
- **Formula:** `dθᵢ/dt = ωᵢ + (K/N) Σⱼ sin(θⱼ - θᵢ)`

**#17: FitzHugh-Nagumo Oscillatory Attention**
- **In Nature:** Neural limit cycle oscillations
- **Innovation:** Attention that oscillates, periodically scanning inputs
- **Key Feature:** Temporal multiplexing via oscillations

**#18: Van der Pol Routing**
- **In Nature:** Heartbeat, breathing, neural bursting
- **Innovation:** Oscillatory gating between expert networks
- **Key Feature:** Self-sustaining periodic routing

### ⚙️ **Energy & Regulation (6 architectures)**

**#7: Energy-Aware Neurons (ATP Budgeting)**
- **In Nature:** Neurons track ATP, can't fire when depleted
- **Innovation:** Each neuron has ATP pool, threshold rises when depleted
- **Key Feature:** Automatic sparsity (60-80%)

**#9: Dual-Channel Neurons (Fast + Slow)**
- **In Nature:** Ca²⁺ signaling (9,633 formulas) - fast electrical + slow modulation
- **Innovation:** Fast pathway modulated by slow state (τ_slow = 0.9)
- **Key Feature:** Meta-learning via slow channel

**#10: Multi-Timescale RNN**
- **In Nature:** Neural diversity (interneurons fast, pyramidal slow)
- **Innovation:** Heterogeneous time constants per neuron
- **Key Feature:** Multi-resolution temporal processing

**#13: Allosteric Regulation Layer**
- **In Nature:** PFK1 enzyme (ATP inhibits, AMP activates)
- **Innovation:** Layer with inhibitor and activator signals
- **Key Feature:** Multi-signal integration

**#14: Homeostatic Plasticity Layer**
- **In Nature:** BCM sliding threshold
- **Innovation:** Self-stabilizing layer adjusting thresholds
- **Key Feature:** No normalization layers needed

**#15: Bistable Switch (Toggle Circuit)**
- **In Nature:** Genetic toggle switch (2 mutual repressors)
- **Innovation:** Binary memory without storage (hysteresis)
- **Key Feature:** Sharp decisions, noise resistance

## Database Schema

```sql
CREATE TABLE novel_architectures (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    description TEXT NOT NULL,           -- What it does
    use_in_nature TEXT NOT NULL,         -- Biological implementation
    architecture TEXT NOT NULL,          -- Full code (PyTorch/pseudo-code)
    source TEXT NOT NULL,                -- Original formula(s)
    created_date TEXT DEFAULT CURRENT_TIMESTAMP
);
```

## Usage in Research/Development

### Quick Integration

```python
# Import from NOVELTY.db
import sqlite3

conn = sqlite3.connect('NOVELTY.db')
cur = conn.cursor()

# Get E.coli Metabolic Loss code
cur.execute("SELECT architecture FROM novel_architectures WHERE id=1")
code = cur.fetchone()[0]

print(code)  # Full PyTorch implementation
exec(code)   # Or parse and integrate
```

### Search by Use Case

```python
# Find architectures for energy efficiency
cur.execute("""
    SELECT name, architecture
    FROM novel_architectures
    WHERE description LIKE '%energy%' OR use_in_nature LIKE '%ATP%'
""")

for name, code in cur.fetchall():
    print(f"{name}:\n{code}\n")
```
