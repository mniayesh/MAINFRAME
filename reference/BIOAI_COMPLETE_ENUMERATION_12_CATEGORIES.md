2. Vesicle uptake of neurotransmitter
3. Vesicle transport to terminal
4. Docking at active zone
5. Priming (maturation)
6. Calcium-triggered fusion (exocytosis)
7. SNARE complex formation
8. Membrane fusion
9. Neurotransmitter release
10. Membrane retrieval (endocytosis)

### 5.5 Circuit Mechanisms

**Lateral inhibition mechanism:**
- Excitatory input to neuron → neuron firing
- Neuron firing → activation of inhibitory interneuron
- Inhibitory interneuron → inhibition of neighboring neurons
- Result: sharpened response peak, suppressed neighbors

**Recurrent excitation mechanism:**
- Excitatory input to principal cell
- Principal cell fires
- Collateral connection to other principal cells
- Amplification of activity
- Bistable states or persistent activity possible

**Disinhibition mechanism:**
- Inhibitory input → inhibitory interneuron activation
- Inhibitory interneuron inhibits inhibitory output neurons
- Net result: disinhibition of target population

**Winner-take-all mechanism:**
- Multiple inputs compete
- Lateral inhibition between competing units
- Positive feedback to winning unit
- Negative feedback to losing units
- Single dominant output

**Oscillatory coupling mechanism:**
- Inhibitory-excitatory loop
- Rebound excitation after inhibition
- Rhythmic firing emerges
- Frequency set by membrane time constants and connection strengths

**Pattern completion mechanism:**
- Partial cue activates attractor network
- Recurrent excitation spreads activity
- Recall of complete pattern
- Useful for memory retrieval

### 5.6 Plasticity Mechanisms

**Spike-timing dependent plasticity (STDP) mechanism:**
- Presynaptic spike causes transmitter release
- Postsynaptic spike causes back-propagating action potential
- If pre→post (causal): coinciding Ca2+ signals → LTP
- If post→pre (acausal): calcium levels low → LTD
- STDP window: tens of milliseconds

**Hebbian plasticity mechanism:**
- Presynaptic activity + postsynaptic activity → weight increase
- (Co-activation strengthens connection)
- Molecular basis: postsynaptic calcium during presynaptic release

**Neuromodulator-dependent plasticity mechanism:**
- Dopamine (reward) → increases LTP probability, decreases LTD
- Dopamine acts via D1/D2 receptors → kinase/phosphatase balance shift
- Serotonin → modulates learning rates depending on context
- Acetylcholine → gates plasticity (needed for learning)

**Synaptic tagging mechanism:**
- Recent activation → "tag" placed on synapse
- Plasticity-related proteins (PRP) synthesized and delivered
- Tagged synapses capture PRP
- Untagged synapses do not
- Selective strengthening via tagging

**Retrograde signaling mechanism:**
- Postsynaptic calcium rise or depolarization
- Endocannabinoid or other retrograde messenger synthesis
- Retrograde messenger diffuses to presynaptic terminal
- Presynaptic receptor activation
- Decrease in release probability

# CATEGORY 9: CONSTRAINTS
## Rules, limits, and regularities that restrict possibilities

### 9.1 Physical Constraints

**Metabolic constraints:**
- Limited ATP availability
- Energy cost of neurotransmitter synthesis
- Energy cost of action potentials

- Lactate accumulation limits sustained activity

**Wiring constraints:**
- Axons take shortest paths (volume minimization)

- Conduction velocity varies with axon diameter (tradeoff: cost vs. speed)
- Myelination improves conduction but is metabolically costly
- Long-range connections more metabolically expensive

**Temporal constraints:**
- Synaptic transmission delay (~1 ms)
- Action potential refractory period (1-10 ms)
- Dendritic filtering time constant (10-100 ms)
- Membrane time constant limits integration window
- Conduction time dependent on distance/velocity

**Size constraints:**
- Neuron soma size (10-100 μm)
- Dendritic spine size (0.5-2 μm)
- Synaptic cleft width (20 nm)
- Active zone dimensions (40-200 nm)
- Vesicle diameter (40 nm)

**Mechanical constraints:**
- Intracranial pressure limits brain size
- Skull constraints brain expansion
- Metabolic rate scales with brain mass
- Column spacing limited by cortical thickness
- Axon bundling in white matter

**Gene regulation constraints:**

# CATEGORY 10: REPRESENTATIONS
## Information encoding formats and schemes

### 10.1 Neural Encoding Schemes

**Rate coding:**
- Firing rate encodes stimulus intensity
- Higher rate = stronger stimulus
- Temporal average (integrate over 100-500 ms)
- Noisy (Poisson variability)
- Energy efficient for low-frequency signals

**Temporal coding:**
- Precise spike timing encodes information
- Spike latency (time-to-first-spike)
- Inter-spike intervals
- Phase locking to oscillations
- Synchrony between neurons

**Population coding:**
- Distributed representation across neurons
- Population vector sum
- Tuning curves specify encoding
- Redundancy (single stimulus drives many neurons)
- Robust to noise
- Allows linear decoding (population vector decoding)

**Sparse coding:**
- Few neurons active per stimulus
- High coding efficiency
- Super-sparse: single neuron codes for stimulus (grandmother cells)
- K-sparse: k% of neurons active
- Disadvantages: lower robustness

**Distributed coding:**
- Representation spread across many neurons
- Each neuron contributes to multiple representations
- High capacity
- Robust (single neuron loss < impact)
- Similarity structure preserved (similar stimuli → similar patterns)

**Combinatorial coding:**
- Specific neuron combinations encode information
- Example: place cell firing pattern encodes location
- Example: neuronal ensemble codes
- Exponential coding capacity
- Requires neural decoder

### 10.2 Feature Representations

**Sensory features:**
- Visual: contrast, orientation, color, motion direction, spatial frequency
- Auditory: frequency, intensity, temporal modulation, sound location
- Somatosensory: position, velocity, force, texture
- Olfactory: chemical identity, concentration, quality
- Gustatory: taste modality (sweet, salty, sour, bitter, umami)

**Motor features:**
- Hand position (extrinsic/intrinsic coordinates)
- Hand velocity
- Muscle activation patterns
- Joint angles
- Movement direction

**Cognitive features:**
- Task (what task is being performed?)
- Reward (expected outcome value)
- Choice (which option to select)
- Category (which category does stimulus belong to?)
- Uncertainty (confidence in decision)

### 10.3 Coordinate Systems and Reference Frames

**Retinocentric (eye-centered):**
- Visual coordinates relative to retina
- Used in early visual cortex
- Changes with eye movements

**Head-centered:**
- Coordinates relative to head orientation
- Used in parietal cortex (partially)
- More stable across eye movements

**Body-centered:**
- Coordinates relative to body
- Used for somatosensory and motor

**World-centered (allocentric):**
- Absolute spatial coordinates
- Used for navigation
- Independent of body/eye position

**Gaze-centered:**
- Coordinates relative to gaze direction
- Hybrid between retinocentric and head-centered

### 10.4 Population Codes and Manifolds

**Low-dimensional manifolds:**
- Neural population activity lies on lower-dimensional manifold
- Dimensionality reduction via PCA, ICA, manifold learning
- Suggests many neurons share common patterns
- Examples: activity manifolds in motor cortex, population codes in sensory systems

**Gaussian manifolds:**
- Activity variance along principal components
- Gaussian structure in reduced space
- Enables neural decoding via Gaussian decoders

**Nonlinear manifolds:**
- Complex geometry in neural space
- Requires nonlinear dimensionality reduction (t-SNE, autoencoders)
- Reveals hidden structure

**Representational geometry:**
- Similarity structure encoded in population patterns
- Representational Similarity Analysis (RSA)
- Similar items → similar neural patterns
- Abstraction levels (perceptual similarity vs. semantic similarity)

### 10.5 Attractor States and Dynamics

**Point attractors:**
- Neural activity converges to fixed point
- Represents stable memory or decision
- Example: working memory storage in prefrontal cortex

**Limit cycle attractors:**
- Neural activity cycles through repeating pattern
- Represents oscillatory dynamics
- Example: rhythmic motor patterns

**Ring attractors:**
- Neural activity forms stable pattern on circle
- Encodes continuous circular variable (angle, direction)
- Example: directional tuning in motor cortex
- Rotation of pattern encodes variable value

**Chaotic attractors:**
- Complex, aperiodic neural dynamics
- Useful for flexible, variable outputs
- Example: cerebellar learning

**Multi-stable attractors:**
- Multiple stable states
- Switching between states via input
- Example: decision-making (bistable)

### 10.6 Semantic Representations

**Semantic space:**
- Concepts represented as points in high-dimensional space
- Distance = semantic similarity
- Clustering = concept categories
- Axes = latent semantic dimensions

**Word embeddings:**
- Word2Vec, GloVe, FastText
- Distributed representation of word meaning
- Geometry preserves semantic relationships
- Example: "king" - "man" + "woman" ≈ "queen"

**Distributed semantics:**
- Meaning distributed across many neurons
- Components: core, shared, property dimensions
- Allows generalization to novel concepts

**Categorical structure:**
- Hierarchical organization (dog is-a animal)
- Superordinate categories
- Basic-level categories
- Subordinate categories

### 10.7 Temporal Representations

**Time cells:**
- Neurons tuned to elapsed time within episode
- Activity profile shows time selectivity
- Found in hippocampus, prefrontal cortex
- Encode scalar time representation

**Temporal context vectors:**
- Time represented as evolving vector
- Similarity structure encodes temporal distance
- Predicts memory for temporal intervals

**Sequence representations:**
- Sequences represented as ordered neural patterns
- Replay of sequences during sleep
- Forward sequences (future prediction)
- Backward sequences (past recall)

**Oscillatory representations:**
- Theta-gamma coupling encodes temporal windows
- Theta phase codes stimulus identity
- Gamma codes local processing
- Cross-frequency coupling → sequence representation

### 10.8 Spatial Representations

**Place cells:**
- Neurons fire when animal in specific location
- Firing field size (30-100 cm)
- Form cognitive map of environment
- Found in hippocampus

**Grid cells:**
- Neurons fire at regular intervals across space
- Hexagonal firing pattern
- Multiple scales/modules
- Found in entorhinal cortex
- Metric representation of space

**Head direction cells:**
- Neurons tuned to head direction (0-360°)
- Directional selectivity
- Found in postsubiculum, ADN, etc.
- Encodes heading direction

**Boundary cells:**
- Neurons fire at environmental boundaries
- Border selectivity (which boundary)
- Found in entorhinal cortex, subiculum
- Encodes environmental structure

**Distance representations:**
- Neurons code distance from location/object
- Gradient representation
- Useful for navigation and motor planning

### 10.9 Value Representations

**Reward value:**
- Expected future reward (discounted)
- Encoded in ventromedial prefrontal cortex (vmPFC)
- Dopamine signal encodes prediction error (actual-expected)
- Scales activity: higher value → higher firing

**State value:**
- Value of being in particular state
- Used for planning
- Ventral tegmental area (VTA) dopamine neurons encode

**Action value:**
- Value of taking specific action in state
- Orbitofrontal cortex, dorsolateral prefrontal cortex
- Used for action selection

**Risk representation:**
- Uncertainty in reward prediction
- Encoded separately from value
- Variance coding (spread of possible outcomes)

**Effort representation:**
- Cost of action
- Anterior insula, dorsal anterior cingulate
- Trade-off with reward value

### 10.10 Cognitive/Abstract Representations

**Task representation:**
- What task being performed
- Encoded in prefrontal cortex
- Changes neural processing in downstream areas
- Biases sensory processing

**Category representation:**
- Categorical membership
- Categorical vs. continuous dimensions
- Distributed across neurons
- Example: face vs. non-face in IT

**Concept representation:**
- Abstract entities (numbers, objects, ideas)
- Distributed across multiple areas
- Combines sensory, motor, and semantic features
- Embodied cognition

**Syntax/structure representation:**
- Grammatical structure of sentences
- Hierarchical structure
- Rule-based operations on elements

**Intention representation:**
- Current goal/intention
- Prefrontal and parietal cortex
- Guides behavior planning

**Other's mental state:**
- Representation of beliefs, desires, goals of others
- Theory of mind
- Found in temporo-parietal junction, mentalizing areas

### 10.11 Memory Representations

**Episodic memory representation:**
- Distributed pattern across hippocampus and cortex
- Context-dependent retrieval
- Configural representation (binds elements)

**Semantic memory representation:**
- Stable, abstracted knowledge
- Cortical storage
- Context-independent
- Categorical organization

**Procedural memory representation:**
- Basal ganglia and cerebellum
- Implicit (not consciously accessible)
- Stored as association between state and action

**Working memory representation:**
- Persistent activity in prefrontal cortex
- Capacity-limited (~3-4 items)
- Delay-period activity encodes maintained information

### 10.12 Error and Prediction Signals

**Prediction error:**
- Difference between predicted and actual outcome
- Dopamine neurons encode
- Used for learning
- Scales with surprise

**Temporal difference error:**
- V(t+1) - V(t) - immediate reward
- Used in reinforcement learning
- Separates state prediction from reward prediction

**Prediction signal:**
- Top-down prediction of expected input
- Used in predictive coding
- Subtracted from bottom-up input
- Error = input - prediction

**Surprise signal:**
- Novel, unexpected event
- Triggers attention
- Violates expectation
- Dopamine (novelty) and salience network encode

# CATEGORY 12: COMPUTATIONS
## Mathematical transformations and algorithmic operations

### 12.1 Linear Computations

**Matrix multiplication:**
- y = Wx (linear transformation)
- Feedforward network layer
- Implemented by synaptic connections (sparse matrix)
- Recurrent connections (W in recurrent networks)

**Convolution:**
- Local receptive field (filters)
- Implemented by local connectivity
- Used in sensory processing (V1, A1)
- Preserves spatial structure

**Correlation:**
- Similarity measure
- r = <x, y> / (||x|| ||y||)
- Used in pattern matching
- Implemented by dot product of neural activity

**Linear regression:**
- y = mx + b (learned fit)
- Least-squares optimization
- Implemented by perceptron learning rule
- Used for supervised learning

**Least-squares minimization:**
- Minimize ||y - Wx||²
- Hebbian-like learning rules approximate
- Gradient descent on loss function

### 12.2 Nonlinear Computations

**Threshold nonlinearity:**
- y = 1 if x > θ, else 0
- Binary threshold
- Implements discrete decision
- Implemented by action potential generation

**Sigmoid activation:**
- y = 1 / (1 + e^(-x))
- Smooth threshold
- Squashes to (0,1)
- Approximates firing rate normalization

**ReLU activation:**
- y = max(0, x)
- Half-wave rectification
- Sparse representation
- Implemented by some neural mechanisms

**Tanh activation:**
- y = (e^(2x) - 1) / (e^(2x) + 1)
- Squashes to (-1, 1)
- Antisymmetric
- Implemented by neural dynamics

**Softmax:**
- y_i = e^(x_i) / Σ e^(x_j)
- Competitive normalization
- Probabilistic interpretation
- Implemented by winner-take-all circuits

**Multiplicative gates:**
- y = control × signal
- Gating computation
- Context-dependent signal passage
- Implemented by dendritic inhibition, neuromodulation

### 12.3 Dynamical Computations

**Integration:**
- Accumulation over time
- ∫ x dt
- Working memory (persistent integration)
- Implemented by recurrent connections, leak

**Differentiation:**
- Rate of change
- dx/dt
- Velocity coding (contrast detection)
- Implemented by synaptic depression, filtering

**Low-pass filtering:**
- Attenuates high frequencies
- Implemented by membrane time constant
- Dendritic filtering
- Integrates over time window

**High-pass filtering:**
- Attenuates low frequencies
- Derivative computation
- Implemented by synaptic depression
- Highlights changes

**Oscillation:**
- Periodic behavior
- Limit cycle
- Implemented by inhibitory-excitatory loops
- Used for rhythmic computation

**Synchronization:**
- Multiple oscillators → phase locking
- Coherence
- Implemented by coupling
- Used for neural communication

### 12.4 Probabilistic Computations

**Bayesian inference:**
- P(H|D) ∝ P(D|H) P(H)
- Posterior ∝ likelihood × prior
- Implemented by neural message passing
- Used for perceptual inference

**Maximum likelihood estimation:**
- argmax P(D|H)
- Find most likely hypothesis
- Implements likelihood function
- Used for parameter estimation

**Marginal inference:**
- P(X) = Σ P(X,Y)
- Integrate out nuisance variables
- Implemented by population averaging
- Used for uncertainty

**Expectation maximization (EM):**
- Iterative optimization of latent variable models
- E-step: expectation of latent variables
- M-step: maximization of parameters
- Implemented by iterative learning

**Importance weighting:**
- p(x) ≈ Σ w_i δ(x - x_i)
- Weighted particles represent distribution
- Sparse representation of distribution
- Implemented by weighted neural populations

**Gibbs sampling:**
- Sample sequentially from conditional distributions
- MCMC method
- Implements posterior sampling
- Used for inference under uncertainty

### 12.5 Optimization Computations

**Gradient descent:**
- θ_new = θ_old - α ∇L
- Minimize loss function
- Steepest descent direction
- Implemented by (approximate) backprop

**Stochastic gradient descent:**
- Update on single sample or mini-batch
- Noisier but faster
- Approximates true gradient
- Implemented by local learning rules

**Backpropagation:**
- Compute gradients via chain rule
- Global loss signal backpropagated
- Biologically implausible (weight transport, symmetric weights)
- Approximated by local learning rules

**Hebbian learning:**
- Δw ∝ pre × post
- Local correlation-based learning
- Biologically plausible
- Not true gradient descent

**Error correction:**
- Δw ∝ error × input
- Minimize prediction error
- Delta rule / Widrow-Hoff
- Implemented by learning rules

**Least mean squares (LMS):**
- Adaptive filter
- Minimizes ||y_target - y_actual||²
- Implements Wiener filter
- Implemented by gradient-like learning

### 12.6 Information-Theoretic Computations

**Entropy:**
- H(X) = -Σ p(x) log p(x)
- Measure of uncertainty
- Implemented by variance/variability in population
- Used for surprise computation

**Mutual information:**
- I(X;Y) = H(X) + H(Y) - H(X,Y)
- Shared information between variables
- Implemented by correlation
- Used for independence testing

**Kullback-Leibler divergence:**
- D_KL(P||Q) = Σ p(x) log(p(x)/q(x))
- Distance between distributions
- Implemented by surprise
- Used for information compression

**Fisher information:**
- How much a parameter affects distribution
- Inverse of variance (for unbiased estimator)
- Implemented by gain modulation
- Used for adaptive precision

**Channel capacity:**
- Maximum bits that can be transmitted
- Limited by noise
- Implemented by neural firing rate dynamics
- Used for information limits

### 12.7 Decision-Making Computations

**Drift diffusion model:**
- dX = b dt + σ dW (stochastic differential equation)
- Evidence accumulation with drift toward boundary
- Accounts for reaction time, accuracy
- Implemented by recurrent networks with competing inputs

**Evidence accumulation:**
- Integrate sensory evidence over time
- Reduce noise via temporal averaging
- Speed-accuracy tradeoff via threshold
- Implemented by leaky integrator

**Value-based decision:**
- V(action) = Σ P(outcome|action) × value(outcome)
- Choose highest value action
- Expected utility maximization
- Implemented by value comparison networks

**Value comparison:**
- Compare options
- Select highest value
- Soft-max competition
- Implemented by WTA circuits

**Risk-sensitive decision:**
- Variance weighting (risk)
- Mean-variance optimization
- Risk aversion (concave utility)
- Risk seeking (convex utility)

**Optimal foraging:**
- Patch choice decision
- Exploitation vs. exploration tradeoff
- Maximize reward rate
- Implemented by threshold-based choice

### 12.8 Coding/Compression Computations

**Principal component analysis (PCA):**
- Find directions of maximum variance
- Linear dimensionality reduction
- Implemented by Hebbian learning on covariance
- Used for redundancy reduction

**Independent component analysis (ICA):**
- Separate independent sources
- Non-Gaussian components
- Implemented by learning rule with sparsity constraint
- Used for source separation

**Sparse coding:**
- Represent signal with few active components
- Energy-efficient representation
- Implemented by L1 regularization or competition
- Used for feature learning

**Vector quantization:**
- Map continuous input to discrete codewords
- Nearest neighbor matching
- Implemented by clustering/WTA
- Used for codebook learning

**Lossless compression:**
- Entropy encoding
- Huffman coding
- Implemented by probability estimation
- Used for efficient coding

**Lossy compression:**
- Rate-distortion optimization
- Tradeoff: fidelity vs. coding cost
- Implemented by dimensionality reduction
- Used for feature extraction

### 12.9 Sequence/Pattern Computations

**Temporal sequence learning:**
- Learn associations between sequential events
- Predict next item in sequence
- Implemented by recurrent dynamics
- Used for language, action sequences

**Hidden Markov model (HMM):**
- Latent state + observations
- State transitions + observation probabilities
- Viterbi algorithm for decoding
- Forward algorithm for inference
- Implemented by hierarchical networks

**Autoregressive model:**
- p(x_t | x_{t-1}, x_{t-2}, ...)
- Current state depends on history
- Implemented by recurrent networks
- Used for time series prediction

**Pattern completion:**
- Partial cue → complete pattern
- Associative retrieval
- Implemented by attractor networks
- Used for memory recall

**Novelty detection:**
- Compare input to learned distribution
- Surprise signal when novel
- Implemented by mismatch detection
- Used for attention and learning

**Sequence generation:**
- Output sequence given prompt
- Forward simulation
- Implemented by recurrent dynamics
- Used for action planning, imagination

### 12.10 Error-Related Computations

**Prediction error:**
- E = actual - predicted
- Surprise signal
- Implemented by comparison unit
- Used for learning and attention

**Temporal difference error:**
- δ = r + γV(s_{t+1}) - V(s_t)
- Value-function error
- Dopamine neurons encode
- Used for value learning

**Perceptual error:**
- Mismatch between prediction and input
- Deviance signal
- Used for predictive coding
- Detected by mismatch negativity (event-related potential)

**Motor error:**
- Difference between intended and actual movement
- Sensory prediction error
- Used for motor learning
- Detected by cerebellum

**Reward prediction error:**
- δR = r - V(s)
- Difference between expected and actual reward
- Dopamine signal
- Used for RL

**Conflict detection:**
- Multiple competing responses
- Uncertainty/ambiguity
- Used for error correction
- ACC (anterior cingulate cortex) encodes

### 12.11 Normalization Computations

**Divisive normalization:**
- y_i = x_i / (σ + Σ x_j)
- Gain control
- Contrast normalization
- Implemented by divisive inhibition

**Subtractive normalization:**
- y_i = x_i - mean(x)
- Mean subtraction
- Z-scoring
- Implemented by feedback inhibition

**Multiplicative gain modulation:**
- y = gain × x
- Attention-like modulation
- Implemented by neuromodulatory inputs

**L2 normalization (unit norm):**
- y = x / ||x||
- Normalize vector length
- Directionality preserved, magnitude removed
- Implemented by competitive normalization

**Softmax normalization:**
- Probabilistic normalization
